# EduMarket 🎓

> **Buy, Sell, and Exchange Student Resources**

EduMarket is a peer-to-peer student marketplace designed to help university and college students buy, sell, and exchange affordable textbooks, electronics, calculators, study notes, hostel items, and campus services.

---

## 🚀 Features

- **Peer-to-Peer Marketplace**: Connects students directly to trade academic and living essentials.
- **Categorized Browsing**:
  - 📚 Textbooks
  - 💻 Electronics & Laptops
  - 🔢 Calculators
  - 📝 Study Notes
  - 🛠️ Student Services
  - 🏠 Hostel & Dorm Items
  - ✨ Others
- **Featured Listings**: Showcase top deals and popular campus listings.
- **Student Registration & Authentication**: Safe and structured onboarding for student buyers and sellers.
- **Responsive Design**: Optimized for mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom styling)
- **Backend**: PHP, Python
- **Server Environment**: Apache / XAMPP

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/PricileMefang/EduMarket.git
   ```
2. **Move to web server directory**:
   - If using XAMPP, place the folder in `C:/xampp/htdocs/EduMarket`.
3. **Start Apache**:
   - Open XAMPP Control Panel and start the **Apache** service.
4. **Access the Application**:
   - Open your browser and navigate to `http://localhost/EduMarket/index.html` or `http://localhost/EduMarket/register.php`.
